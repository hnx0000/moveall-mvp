# 구름 비숑 커스텀 펫

원본 비숑의 얼굴과 픽셀 질감을 유지하면서 앱에서 바로 재생할 수 있게 정리한 애니메이션 에셋입니다.

- `idle.webp`: 6프레임 대기 루프 (150ms/프레임)
- `walk.webp`: 8프레임 이동 루프 (95ms/프레임)
- `reaction.webp`: 6가지 반응 미리보기
- `*-sheet.png`: 512×512 셀로 정규화한 투명 스프라이트 시트
- `frames/`: 프레임별 투명 PNG
- `pet.json`: 재생 속도, 프레임 크기, 반응 순서 메타데이터
- `source/`: ImageGen 원본 시트

반응 프레임 순서는 `joy`, `curious`, `excited`, `surprised`, `sleepy`, `affectionate`입니다. 실제 앱에서는 반응 시트를 연속 재생하기보다 필요한 프레임을 골라 짧게 보여주는 방식이 자연스럽습니다.

소스 시트를 다시 가공하려면 이 폴더에서 `build_pet_assets.py`를 실행합니다. 출력은 항상 512×512 프레임, 하단 기준선 470px로 맞춰져 움직일 때 크기와 발 위치가 크게 튀지 않습니다.
