# GROOV Tab Lab

독립된 하단 2번 탭 비교용 MVP. 기존 Expo 앱·API·DB를 변경하거나 호출하지 않습니다.

실행: 저장소 루트에서 `node prototypes/tab-lab/server.mjs`

주소: http://localhost:8092 (127.0.0.1에만 바인딩)

테스트: `node --test prototypes/tab-lab/model.test.mjs`

## 체험 흐름

- 좌측 TODAY / SPORT / TODAY × SPORT를 전환합니다.
- 추천 운동 → 세션 시작 → 타이머 일시정지/재개 → 입력한 운동량으로 체험 완료 → 목표 및 기록에 반영.
- SPORT와 하이브리드에서 6종목 전환, 기록·메달·코스/실내 세션·피드·크루 상세를 확인합니다.
- 목표 선택, 미션 참여 취소, 샘플 사용자 팔로우 토글이 작동합니다.
- +는 공통 통합 기록/콘텐츠 진입을 체험하는 축소판입니다. 사진 선택·배경 선택·텍스트 이동을 제공합니다. 전체 편집툴의 대체 구현은 아닙니다.
- 우측 4종 사용자 체크리스트에 직접 점수를 입력하고 메모와 후보를 저장할 수 있습니다. 평가 모아보기에서 JSON 다운로드가 가능합니다.

## 범위와 저장

모든 사용자·수치·코스·날짜는 비교용 샘플입니다. 실제 GPS, 지도 길 안내, 훈련 처방, 실제 SNS 전송은 없습니다. 완료량은 사용자가 입력한 시뮬레이션입니다.

브라우저 localStorage `groov-tab-lab-v1`에 체험 기록·참여·목표·평가를 저장합니다. 사진은 현재 편집 창 안에만 존재하며 서버에 업로드하지 않습니다. 콘텐츠 저장은 코멘트만 저장하며 실제 이미지 파일이나 게시물을 만들지 않습니다. 초기화는 이 키의 데이터만 대상으로 합니다.

기존 저장소의 사진 파일을 읽기 전용으로 제공합니다. 외부 폰트가 연결되지 않아도 시스템 폰트로 작동합니다.
