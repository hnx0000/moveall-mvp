# GROOV Korea 2.5D Map MVP

메인 앱과 분리된 전국 지역 리그 지도 프로토타입입니다.

## 실행

```powershell
node server.mjs
```

브라우저에서 `http://127.0.0.1:8095/`를 엽니다.

## 구현 범위

- 대한민국 250개 시군구 경계를 WGS84 좌표로 렌더링
- 실제 지도 타일 위 점수 기반 2.5D 높이, 과열도, 라벨 스케일링
- 자유 이동·확대·회전·기울기와 전국/권역 빠른 이동
- 전국 및 선택 권역 실시간 랭킹, 1~3위 체스말형 랜드마크
- 브라우저 위치 권한 기반 내 위치 이동, 운동 화면의 별도 GPS 기록
- 지도 이미지 원본은 제작 파일로만 보존하며 디자인 보관함 UI는 제거

점수 갱신은 MVP 검증용 로컬 시뮬레이션입니다. 실제 서비스에서는 동일한 화면 모델을 지역 리그 API/실시간 구독 데이터로 교체합니다.

기본 지도는 API 키 없이 실행할 수 있도록 OpenFreeMap/OSM을 사용합니다. Google Maps 기반 구현은 아닙니다. Google 기반으로 전환하려면 Maps Platform 키·이용조건 확인과 별도의 렌더링 통합 작업이 필요합니다.

## 도봉 · 쌍문 · 러닝 상세 지도 3종

메인 GROOV 앱과 데이터·페이지를 분리한 동일 MVP 안에 세 화면을 추가했습니다.

| 인증 동네 | 상단 인증 동네 연결 | 실제 계정의 인증 동네로 이동. 고정된 쌍문1동 바로가기는 제거 |
| 러닝 ZOOM 17 | http://127.0.0.1:8095/detail.html?view=run | 정확히 17.0 배율로 시작, 주황색 경로, 이동 마커·거리·시간·페이스 |

- 드래그·휠·핀치로 이동/확대, 2D/2.5D 전환, 전체 범위 보기 지원.
- 최초 화면에는 예시 코스가 없습니다. `나만의 코스`에서 생성·선택한 경로만 미리보기로 사용합니다.
- 내 코스 재생은 12배속 모의 이동이며 실제 운동 기록으로 저장하거나 탐험률·리그 점수에 반영하지 않습니다.
- 지도 이동 시 자동 따라가기를 해제하고, 따라가기 버튼으로 복귀합니다. 17 버튼은 현재 위치를 유지하며 정확히 ZOOM 17로 복귀합니다.
- 전국 화면과 동일한 무채색 중심·GROOV 주황 포인트를 사용하되, 상세 도로는 이미지 확대가 아닌 실제 벡터 지도입니다. 경계/거리/건물을 임의로 그림으로 만들지 않았습니다.

### 실제 GPS 실험과 한계

`내 GPS로 기록`은 명시적인 위치 권한 허용 후 이 기기의 `watchPosition`으로 전경 추적합니다. 예시 좌표와 실제 GPS는 섞지 않습니다. 부정확한 좌표·시간 역전·비현실적 속도/점프를 걸러내고, 긴 수신 공백은 선으로 임의 연결하지 않습니다.

종료 확인 후 GPS와 타이머가 함께 중지됩니다. 실제 GPS 기록 중 다른 지도 탭으로 이동할 때도 먼저 종료 여부를 확인합니다. 페이지 이탈은 기록을 중지합니다.

이 별도 MVP에는 영구 저장·백그라운드 GPS·실기기 주행 검증이 포함되지 않습니다. 새로고침하면 실험 경로는 사라집니다. 휴대폰에서는 HTTPS 또는 신뢰 가능한 로컬 개발 환경이 필요합니다. `127.0.0.1`은 현재 PC에서만 열립니다.

### 데이터 출처 / 검증

- 경계: SGIS 기반 `vuski/admdongkor` 2026-07-01 자료. 출처·고정 리비전·라이선스는 `assets/dobong-boundary-source.md` 참고. 통계용 일반화 경계이며 지적측량 자료가 아닙니다.
- 도로·건물: OpenFreeMap / OpenMapTiles / OpenStreetMap. 원본에 없는 골목이나 건물은 추가 생성하지 않습니다.
- 과거 예시 원본은 `assets/ssangmun-running-route.geojson` 및 `assets/ssangmun-osm-source.osm`에 테스트 자료로만 보존합니다. 실행 화면에서는 불러오지 않습니다.
- 순위·점수·참여율은 5초 간격 로컬 시뮬레이션이며 GROOV 운영 API에 연결하지 않았습니다.
- 테스트: `npm run check`

## 2026-09-08 지도 시스템 개선

- 핀은 출발점 포함 30개. 핀 클릭으로 제거·반환점 지정, 위치는 드래그로 이동. 별도 위치 수정 버튼 제거.
- N번 반환점 지정 시 이후 수동 핀은 제거하고 출발~N번의 실제 라우팅 좌표를 역순으로 복제. 자동 귀환 좌표는 수동 핀 30개 제한에 포함하지 않음. 사이클은 역방향 경로가 같은 길로 통행 가능한지 추가 확인하며 확인 실패 시 왕복 생성 거절.
- 상세 주소·장소명 검색 후 명시적으로 결과 선택. 출발/도착 검색은 각기 독립적이며 이후 경로 자동 계산. 입력할 때마다 외부 자동완성을 호출하지 않음.
- 거리 1~30km, 하천/공원/주변 운동길, 조용한 길 우선, 왕복 자동 생성. 경로 실제 거리는 요청 대비 ±20%를 넘으면 제안하지 않음. 화면에는 계산된 실제 거리 표시.
- 러닝/사이클/등산 모드를 분리. BRouter의 배포된 보행 프로필은 `hiking-mountain`이며 러닝은 난도 제한, 등산은 난도 제한+숲 선호 적용. 존재하지 않는 `walking` 프로필을 사용하지 않음. 하천·소음·교통 선호는 실제 지원 옵션에 0/1로 전달.
- 주변 경로 검색이 실패하면 실제 라우팅 그래프에서 후보를 다시 찾음. 임의 직선은 절대로 경로로 표시하지 않음. 하천 자동 코스는 BRouter 분류 거리 중 하천 인접 비중 40% 이상을 확인해야 함. 이 분류는 통제·침수·공사에 대한 실시간 접근성 보증이 아님.
- 등산 지형 토글: Mapterhorn 30m DEM, 과장 없는 2.5D, 명암, 실제 DEM에서 계산한 20/50m 등고선, 지도에 등록된 산책/등산로 표시. 고도 데이터 없는 구간에 등고선을 합성하지 않음. 경로 고도 최저/최고·상승/하강·경사 추정치를 표시.
- 경계 광선의 모서리는 round join/cap으로 렌더링하고 축소 시 폭/블러 축소. 선택된 Polygon/MultiPolygon과 내부 구멍은 그대로 유지하며 약 4 화면 픽셀에 해당하는 얕은 elevation만 적용.
- 전국/상세 하단 HUD는 visualViewport와 safe-area 기준으로 배치. 기기 높이보다 커지는 min-height 제거.

### 서비스 교체 지점

`map-services.mjs`: `createMapServices({routing,geocoding,corridors,environment,exploration})`.
화면은 `map-client.mjs`의 같은 출처 API만 사용합니다. 서버용 키는 브라우저로 내려보내지 않습니다.

- `GROOV_ROUTING_URL`: BRouter 호환 endpoint (기본 brouter.de).
- `GROOV_GEOCODING_URL`: Photon 호환 endpoint (기본 photon.komoot.io).
- `KAKAO_REST_API_KEY`: 선택적 서버 전용 한국 주소/키워드 검색 공급자. 미설정 시 Photon 사용.
- `GROOV_CORRIDOR_URL`: Overpass 호환 endpoint. 자동 생성 후보 검색용으로만 사용.
- 지형: `mountHikingTerrain`에 raster-dem source를 주입 가능.

환경변수는 실행 셸에서 설정합니다. `server.mjs`는 기본적으로 127.0.0.1만 수신하며 PC 로컬 개발 데이터 저장소입니다. 공개 서비스용 인증·사용자별 저장소는 별도 통합이 필요합니다.

### 이번 범위에 포함하지 않은 장기 기능

`environment-layers.mjs`는 시간·영역·취소 가능한 독립 공급자와 데이터 유효기간을 정의합니다. 강수, 레이더 프레임, 구름, 태풍, 수온/파고를 붙일 수 있으나 실제 기상 API는 아직 연결하지 않았습니다. 만료/미설정 데이터를 날씨 좋음으로 판단하지 않습니다.

탐험률은 검증된 GPS 세그먼트와 버전이 고정된 실제 운동길 그래프를 대조해야 합니다. `createExplorationStore`는 공급자 계약만 준비하며, 핀/모의 코스를 실제 탐험으로 인정하지 않습니다. 아직 안 간 길, 새 구간 거리, 동네 완주 및 날씨 기반 오늘의 운동 추천은 아직 표시/계산하지 않습니다. 순환 코스·언덕 최소·새로운 길 조건도 후속 범위입니다.

### 실제 서비스 검증

- 우이천: 연결된 하천 보행/자전거길 라우팅 성공, 약 5.76km.
- 중랑천: 자전거길 라우팅 및 역방향 왕복 확인 성공, 약 1.32km 편도.
- 도봉구 우이천로 308, 마들로 656, 중구 세종대로 110: 건물번호를 보존하는 검색 결과 확인.
- 우이천 인근에서 러닝 7km/하천/조용한 길/왕복 → 6,997m, 하천 인접 분류 88.6%, 귀환 좌표 대칭 확인. 외부 데이터 갱신에 따라 재실행 결과는 달라질 수 있음.
- 현장 주행·통행 제한·기상 안전성 검증은 이 자동/브라우저 테스트에 포함되지 않음.
- 브라우저 검증: 최초 코스 0개/재생 비활성화, 주소 출발·도착 생성, 7km 자동 생성, 핀 클릭·위치 수정·드래그·제거, 반환점 지정, 등산 지형/등고선과 고도 라벨 표시 확인. 오류 로그 없음.
- 390×500 세로 / 844×390 가로에서 하단 포인트 카드의 모든 경계가 화면 내부에 위치함을 확인. 브라우저 크기 변경 테스트이며 실제 휴대폰의 키보드·노치 조합은 추가 실기기 확인 필요.
- 구문 검사 및 자동 테스트 35개 통과. 이 작업은 로컬 지도 프로토타입만 수정하며 공개 링크에 배포하지 않음.

## 휴대폰 지도 우선 화면

- 첫 진입: 지도, 상단 이동 링크, 확대/축소 등 핵심 조작, 하단 메뉴만 표시. 랭킹·총점·권역 목록·선택 점수판은 자동으로 펼치지 않음.
- 전국 지도: 하단 `지역 / 랭킹`. 조작 도구는 우측 상단 세로 아이콘. 디자인 보관함 진입 제거.
- 상세 지도: 상단 3탭과 반투명 검색, 좌하단 현황 카드. 하단 메뉴는 제거. 우측 상단 내 위치·코스·도구와 웹 형태의 +/배율/− 묶음. 랭킹은 현황 카드에서 접근.
- 모든 모바일 패널에 닫기 제공. 메뉴 재탭·Escape로 닫기. 닫힌 패널은 화면과 키보드 탐색에서 제외. 다른 패널로 이동해도 편집 중 핀 데이터는 유지.
- 코스 설정 창은 최대 화면 높이 46%로 제한해 지도에 핀을 찍을 공간을 확보. 검색·랭킹은 최대 58%; 키보드/짧은 화면에서는 visualViewport 높이를 추가 제한으로 적용.
- 세로뿐 아니라 1000px 이하·540px 이하 높이의 가로 화면도 모바일 모드. 44px 이상 핵심 터치 영역, 14~16px 기본 조작 텍스트, 안전 영역과 열려 있는 패널에 맞춘 지도 초점 여백.
- GPS 기록 중 코스 설계 진입 제한 유지. 실제 현장 기록은 `현황`에서 접근하며 자동 중단하지 않음.
- `mobile-map.test.mjs`: 초기 접힘, 단일 패널, 회전, 접근성 상태, Escape, GPS 진입 차단, 320×568/390×844/390×500/844×390/키보드 높이의 초점 여백을 코드 테스트로 검증. 새 모바일 화면의 실기기/브라우저 조작 검증은 별도 확인 필요.

## 지도 조작 / 검색 정리 (2026-09-08 후속)

- 위치 수정 버튼 제거. 반환점 해제는 동일한 보조 버튼 그룹의 `편도로 전환` 버튼으로 통일.
- 전국·상세·코스 설계 상태 모두 내 위치 버튼 제공. 매번 새 위치로 이동하며 운동 기록을 시작/정지하지 않음. 중복 요청·권한 거부·시간 초과·늦은 응답 처리.
- 우상단 아이콘은 44px 터치 영역. 내 위치·코스가 위쪽에 오고, 열린 패널은 우측 도구 공간 66px를 남김. 낮은 가로 화면은 도구 레일을 스크롤 가능.
- 토스트의 기존 top과 모바일 bottom 충돌 제거. 높이 자동, 줄바꿈, safe area 적용.
- 동네·상세주소·장소 검색을 하나로 통합. 행정구역은 입력 중 제안하며 전체 결과를 8개씩 더 볼 수 있음. 외부 주소 검색은 명시적 검색 후 수행.
- 선택된 지역은 실제 경계를 유지한 강조와 검색 핀으로 표시. 장소/주소 핀은 코스 핀과 별개이며 새 검색을 선택하면 교체.
- 띄어쓰기 없는 주소·층/호 입력은 건물 주소를 분리해 조회. 도로명+건물번호 또는 동명+지번이 다른 결과는 `주변 후보 · 입력한 주소와 다름`으로 구분. 숫자 불일치를 정확한 주소로 처리하지 않음.
- **남은 외부 데이터 제한:** 현재 서버는 Photon 사용. 노해로147 등 일부 실제 한국 번지가 없으며, 국내 전체 상세주소 해결을 완료한 상태가 아님. 서버 전용 `KAKAO_REST_API_KEY` 설정이 필요. 키를 클라이언트 코드/URL/로그에 넣지 말 것.
- 인증 동네는 고정값이나 다른 사용자의 로컬 저장값을 쓰지 않음. 로컬 앱 `/map-connect`에서 사용자가 명시적으로 연결하면 계정의 onboarding 인증 동네만 전달. origin/source/일회성 nonce, 30일 유효기간 확인. 데모 모드는 인증정보로 인정하지 않음.
- 표시명은 `도봉구 쌍문동` 형식(행정동 번호 생략); 위치 선택에는 원본 동 코드, 시도, 좌표 유지. 동일 구·동명이 여러 지역에 있으면 첫 번째 결과를 임의 선택하지 않음.
- 연결은 페이지 메모리에만 유지. 새로고침/새 지도 페이지에서는 다시 연결. 현재 로컬 앱이 예시 계정 모드라면 연결 안내가 표시되며, 실제 계정 API와 동네 인증 완료 후 연결 가능.
- MY 설정의 로고·보상 보관함 진입도 제거. 제작 이미지·메달 원본과 개발용 시안 파일은 보존.
- 자동 테스트 54개 통과, 지도 JS 구문 검사 및 앱 TypeScript 검사 통과. 이번 후속 UI는 브라우저 조작/실기기 시각 검증 미실시. 공개 사이트·GitHub 배포 변경 없음.

## 전국 상세 지도 HUD 재배치

- `detail-hud.css/mjs`에서 상세 모드의 레이아웃을 분리. 전국 판형 지도의 기존 모바일 메뉴에는 영향 없음.
- 웹·휴대폰 공통 상단 전환: 전국 탐색 / 실제 인증 동네 / 코스·러닝. 인증 연결 전 고정 동네를 노출하지 않음. 탭 안 동네명 갱신 시 탭 구조를 덮어쓰지 않음.
- 검색창은 상단 고정, 배경만 62% 불투명으로 처리하고 글자는 선명하게 유지. 결과는 아래로 펼치며 검색창 오른쪽 투명 영역은 지도 도구의 터치를 막지 않음.
- 현황은 좌하단 축소 카드로 상시 표시. 아직 선택하지 않은 전국 화면에서는 특정 동네 샘플 점수를 내 현황처럼 표시하지 않음. 랭킹 보기·상세 이동은 카드 안에서 접근.
- 세부 도구 버튼은 우상단에서 기울기/북쪽 메뉴를 펼침. 코스와 내 위치도 같은 우측 레일. 확대·현재 배율·축소는 웹과 같은 둥근 단일 그룹.
- 상시 검색창·현황 카드는 기존 모바일 sheet와 inert 관리에서 제외. 코스/랭킹만 상호 배타적 패널로 유지. GPS 기록 중 검색 이동은 차단하며 차단된 검색 결과를 선택 완료로 표시하지 않음.
- 상단 탭·검색의 실제 높이를 관찰해 지도 도구와 카메라 여백을 조절. 320~430px 세로 화면, 낮은 가로 화면, 키보드 표시 상태의 배치 규칙을 분리.
- 자동 테스트 총 58개 및 지도 소스 구문 검사 통과. 새 화면의 브라우저 조작·휴대폰 실기기 시각 검증은 미실시. 로컬 테스트 링크만 갱신하며 공개 사이트는 변경하지 않음.
