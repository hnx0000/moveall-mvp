# 콘텐츠 편집기 개편 — 2026-09-03

## 로컬 구현

- 하단 탭 순서 유지. 중앙 `+` 짧게 누르기 = `/routines` 운동 측정, 420ms 길게 누르기 = `/compose?direct=1`. 길게 누른 뒤 손을 떼어도 측정 화면으로 이동하지 않는다.
- 피드의 인라인 작성 화면 제거. 내 스토리 원은 보기, 독립적인 `+` 버튼은 `/compose?kind=story` 작성.
- 사진 촬영/선택/건너뛰기 → 종목 → 텍스트/지도 기록 선택 → 캔버스 편집 → 본문·게시 설정.
- 사진/지도/제한된 단색 배경, 주황색 GPS 루트 오버레이, 텍스트, 운동 로고, 기록 그룹. 그룹 해제 시 개별 기록 편집. 실제 측정 수치는 편집하지 않는다.
- 드래그 및 두 손가락 확대·회전 제스처 코드와 버튼 조작 지원. 외부 이미지에는 우측 상단 GROOV 로고 고정.
- 예시 루트는 명시적으로 켜야 표시되고 테스트용 표시를 이미지에 포함한다. 운동 기록이나 메달로 저장하지 않는다.
- 공개 범위와 댓글 범위를 각각 적용. 특정 사용자·공유 크루 복수 선택. 댓글 OFF 지원.
- 공유 크루는 작성자 소유의 수신자 목록이다. 실제 팀 가입/초대 기능이 아니다. 게시 시 서버에서 멤버를 확정하고 다른 사용자에게 수신자 목록을 노출하지 않는다.
- 게시 스토리는 24시간 후 피드·상세·댓글·공유에서 차단하며 데이터를 즉시 물리 삭제하지 않는다. 데모 인물의 기존 샘플 스토리는 데모 모드에만 유지하고 ‘미리보기’로 표시한다.
