# GPS 기록 안정화 — 2026-09-11

## 확인된 원인

- 설치된 Expo 57 웹 위치 구현은 Expo 구독 ID와 브라우저 구독 ID를 혼용하고, 브라우저 watch에 오류 콜백을 전달하지 않았다. 네이티브 정확도 옵션도 웹의 `enableHighAccuracy`로 변환되지 않았다.
- 초기 단발 위치 요청은 오래된 캐시를 허용하며 첫 위치를 받기 전까지 타이머/지속 수신이 시작되지 않았다.
- 수신 오류 후 재구독이 없었고, 화면 복귀 때에는 버퍼만 읽었다.
- 복구 과정에서 UI의 마지막 저장 시각 이후에 수집된 실제 네이티브 좌표를 버렸다.
- 지도 전체화면은 첫 좌표 이후 따라가지 않았으며 작은 지도는 매번 각도/확대율을 초기화했다. 내 위치 버튼은 별도의 위치/마커를 만들었다.

## 수정

- 웹 전용 위치 어댑터: 실제 브라우저 구독 ID를 보관·해제, 고정밀/캐시 미사용/15초 타임아웃/오류 전달. Permissions API가 없어도 기록 시작 가능.
- 첫 위치를 기다리지 않고 시간 기록 시작. 위치 무응답 시 가시 상태에서 최대 30초 간격으로 재연결, 화면 복귀 시 재구독, 권한 거부 후 무한 재요청 방지.
- 정지/종료/재시작 후 도착한 구독과 콜백의 세대 검증 및 정리.
- 기존 이상 속도·가속도·정지 흔들림 필터 유지, 오래된 실시간 첫 좌표 추가 차단. 미수신/일시정지 구간의 거리와 선은 만들지 않음.
- 네이티브 백그라운드 기능/서비스 확인, 화면 복귀 시 서비스 재점검, GPS 상태와 별개로 백그라운드 비활성 경고 유지. 앱 루트에서 작업 등록.
- 활성 구간 정보 보존 및 해당 운동의 네이티브 좌표로 확인된 마지막 시각까지만 시간·경로 복구. 미래 시각과 명시적 일시정지/구버전 기록에는 임의 시간 추가 금지.
- 버퍼 삭제는 운동 ID와 현재 실행 여부를 확인. 복구 기록 폐기 시 서비스 중지 및 해당 좌표 버퍼 삭제.
- 기록 중 전체화면/작은 지도 모두 같은 수신 좌표 추적. 카메라 각도·확대율 유지, 직접 끌면 추적 중지, 내 위치로 복귀 시 재개. 별도 위치 요청과 마커가 기록 재개 후 늦게 끼어들지 않도록 취소.
- 웹 화면 유지 요청과 복귀 시 재획득. 타이머는 실제 시각 차이로 계산하며 화면 갱신만 250ms로 낮춤.

## 검증

관련 자동 테스트 66개 통과: GPS 필터/병합, 구독 재연결·권한 거부·늦은 응답, 네이티브 시작 중 일시정지와 종료 경계, 중단 복구, 전체화면 추적/지도 탐색/위치 요청/브리지/검색. 모바일 타입 검사 및 소스 비밀정보 검사 통과.

## 실제 기기 검증은 별도 필요

이 컴퓨터에서 실제 휴대폰 GPS를 받거나 잠금 상태를 재현하지 않았으며, 모의 자동 테스트를 실기기 검증으로 간주하지 않는다.

- 웹/PWA는 OS가 화면 잠금 또는 숨김 페이지에서 GPS·JavaScript를 중단할 수 있다. 화면 유지 API는 자동 잠금을 줄일 뿐 수동 잠금/OS 종료를 막지 못한다. 공유 링크만으로 항상 백그라운드 GPS를 보장할 수 없다.
- 잠금 화면 추적은 Expo Go가 아닌 설치형 개발/배포 빌드와 iOS 항상 위치 권한, Android 백그라운드 권한·위치 포그라운드 서비스가 필요하다. 강제 종료/배터리 절약/권한 회수/기기 전원 꺼짐/GPS 음영에서는 수신 보장이 불가능하다.
- 수신하지 못한 경로를 도로에 맞춰 추측해 만들지 않는다. 현재 경로 한도는 기존 30,000개 좌표를 유지한다.

### 휴대폰 확인 항목

1. 새 권한/기존 권한 각각 운동 시작 후 첫 GPS가 늦어도 시간은 증가하는지.
2. 야외 10분 이동: 지도와 거리·평균 속도/페이스가 지속 갱신되는지.
3. 잠금 5분, 다른 앱 5분, 복귀 후 시간·좌표 확인(웹과 설치형 결과 구분).
4. 위치 서비스 끄기/켜기, 정확한 위치 권한 제한/복원, 신호 음영 후 자동 재연결 확인.
5. 일시정지 중 이동 후 재개: 정지 구간의 거리/직선이 추가되지 않는지.
6. 전체화면 2.5D/확대율 유지, 지도 끌기 후 내 위치 버튼 추적 복귀 확인.
7. 앱 프로세스 재시작 후 확인된 네이티브 구간 복구와 한 번만 저장되는지.
