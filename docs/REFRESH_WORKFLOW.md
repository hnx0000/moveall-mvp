# 최신화 기본 항목

이 프로젝트의 ‘최신화’ 요청에는 다음 항목을 포함한다.

- 최신 개발 내용을 확인하고 검증한 앱을 패널에 연다.
- 외부 공유 링크는 실제 배포된 버전인지 구분해 제공한다. 공개 배포 승인을 생략하지 않는다.
- 개발 대시보드와 그 안의 사용자 검증 체크리스트를 연다.
- `pnpm dashboard:sync`로 `docs/PRODUCT_VALIDATION.md`의 최신 기준을 대시보드 카드에 반영한다. 실제 사용자 검증 완료를 임의로 체크하지 않는다.
- 온보딩은 **`/onboarding-preview` 미리보기 링크**로 연다. 기존 `/onboarding`은 최신화 링크 목록에서 제외한다. 실제 가입 온보딩 기능 자체는 유지한다.
- 미리보기에서는 계정의 완료 기록·설문 응답·동네 설정을 변경하지 않는다.
- 반복 자동화는 중지 상태를 유지한다. 별도 요청 없이 다시 켜지 않는다.
