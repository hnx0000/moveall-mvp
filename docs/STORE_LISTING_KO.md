# GROOV 스토어 등록자료 초안

지원·계정 삭제의 신규 경로는 로컬 구현 및 정적 export를 완료했다. 아래 공개 주소는 다음 배포 후 실제 접근 여부를 확인하고 스토어에 입력한다.

## 카피

- App Store 부제 후보: `운동의 흐름을 기록하고 함께 잇다`
- Google Play 짧은 설명: `운동을 기록하고, 루틴·피드·동네 경쟁으로 꾸준함을 이어가세요.`
- 키워드 후보: `운동기록,러닝,사이클,등산,근력운동,수영,다이빙,루틴,GPS,피트니스`

### 상세 설명

GROOV는 한 번의 운동을 다음 움직임으로 이어 주는 운동 기록 커뮤니티입니다.

러닝, 등산, 사이클, 근력 운동, 수영과 다이빙을 한곳에 기록하세요. GPS 기반 거리와 페이스, 운동 시간, 심박과 종목별 지표를 확인하고, Health Connect와 Apple 건강에서 사용자가 허용한 완료 운동을 가져오거나 내보낼 수 있습니다.

나만의 루틴을 만들고 오늘 할 운동을 체크하세요. 기록 카드를 피드와 스토리에 공유하고, 친구의 기록을 목표로 저장하며, 인증한 동네에서 시즌 기록과 메달에 도전할 수 있습니다.

센서와 GPS 측정값은 기기와 환경에 따라 달라질 수 있으며 GROOV의 정보는 의료 진단이나 치료를 대신하지 않습니다. 운동 중 이상 증상이 있으면 즉시 중단하고 전문가에게 상담하세요.

## 개인정보 공개 입력 기준

최종 바이너리의 SDK와 서버 동작을 대조한 뒤 아래 항목을 콘솔에 입력한다.

| 범주          | 예시                                  | 목적             | 계정 연결 |
| ------------- | ------------------------------------- | ---------------- | --------- |
| 연락처        | 이메일                                | 계정·로그인·지원 | 예        |
| 사용자 콘텐츠 | 게시물, 댓글, 사진, 영상, 탭톡        | 커뮤니티         | 예        |
| 위치          | 운동 중 GPS 경로·고도·정확도          | 실외 운동 기록   | 예        |
| 건강·피트니스 | 운동, 심박, 걸음, 거리, 칼로리        | 기록·동기화      | 예        |
| 식별자        | 사용자 ID, OAuth 제공자 ID, 푸시 토큰 | 인증·알림·보안   | 예        |
| 진단          | API 오류·요청 ID, 향후 crash 정보     | 안정성·보안      | 상황별    |

건강·위치·미디어는 선택 동의이며 광고 타기팅이나 데이터 판매에 사용하지 않는 것으로 신고한다. 정밀 위치는 저장 전에 동네 인증 좌표를 소수 둘째 자리로 낮추지만, 실시간 운동 경로를 처리하므로 위치 수집 자체는 숨기지 않는다.

## 연령 등급·UGC 답변 메모

- 사용자 게시물·댓글·사진·영상과 1:1 탭톡이 있다.
- 신고, 사용자 차단, 금칙어 필터와 관리자 검토 기능이 있다.
- 의료 진단 앱이 아니며 운동 보조 정보를 제공한다.
- 정확한 등급은 App Store Connect와 Play Console 설문 결과로 확정한다. 임의로 낮은 등급을 선택하지 않는다.

## 그래픽과 스크린샷

- 최종 GROOV 아이콘: 1024×1024 PNG, 투명도 없는 원본 필요
- Android adaptive icon foreground/background 별도 필요
- 현재 `docs/screenshots`의 모바일 자료는 390×844, 데스크톱 자료는 1280×720으로 기능 증적용이다. 최종 스토어 기기 규격·최종 UI·개인정보 노출 여부를 다시 확인해야 한다.
- 기존 `moveall-desktop.png`는 256×256의 이전 M 로고이므로 GROOV 최종 아이콘으로 제출하지 않는다.
- 필수 장면 후보: 로그인/온보딩, 오늘의 활동, 실시간 GPS 기록, 루틴, 피드·스토리, 동네 시즌/메달, 내 기록·건강 연동
- 실제 기기 프레임과 스토어가 허용하지 않는 오해성 수치·미구현 기능을 넣지 않는다.

## 심사 메모

- 앱 내 계정 삭제: 내 정보 → 계정 및 보안 → 계정 삭제
- 정책·삭제 URL은 로그인 없이 열 수 있다.
- 위치는 사용자가 운동 기록을 시작한 동안만 사용하며 백그라운드 권한은 진행 중인 운동을 이어 기록하는 목적이다.
- Health 데이터는 사용자가 선택한 완료 운동 가져오기·내보내기에만 사용한다.
- 심사 계정과 테스트 데이터는 실제 제출 직전에 별도로 만들어 제공한다.
