## 이전 중간안: 직각 강제가 아닌 부드러운 상자 무드

사용자가 저장한 루틴 카드 이미지를 기준으로 추가 수정했다.
정보 카드/팝업은 12px, 입력/버튼은 6px, 사진 프레임은 6px의 공통 곡률을 사용한다.
MY의 메달·목표 섹션처럼 의도적으로 직선인 영역은 유지한다.
큰 18–28px 모서리나 긴 캡슐 형태를 절제하되, 아바타·메달·지도 핀·스위치·원형 아이콘은 보존한다.
이 기준이 아래 초기 '각진 정보 카드' 설명보다 우선한다.
로고의 모양/글꼴/비율/색상/크기/위치는 이번 후속 작업에서 변경하지 않는다.
사진/피드·루틴·편집기·지도 패널·설정·알림·댓글·공유·온보딩과 보관함의 UI 외곽을 조정했다.
보관함 안의 과거 메달/기록 디자인 시안 자체는 보존한다.

## 기준과 변경 범위

기준 화면은 로컬 `/profile`. 검정·중성 차콜 바탕, 기존 GROOV 오렌지,
1px 윤곽선, 각진 정보 카드, 작은 영문 보조 제목과 굵은 한글 제목의 위계를 사용한다.
최대 본문 폭 430, 기본 좌우 여백 15. 주요 화면 제목은 20px 수준으로 맞춘다.
읽기용 본문, 수치, 편집 도구는 목적에 맞는 크기를 유지한다.

- `theme.ts`: MY에서만 사용하던 색상을 공통 테마로 이동. 라이트 모드도 중성 계열로 정리.
- `uiLayout`: 화면/정보 패널용 별도 토큰. 기존 radius는 아바타·스포츠 로고·기록 아트워크를 위해 유지.
- `Screen`, `Card`, `PrimaryButton`, `CenterDialog`: 여백, 제목, 테두리, 평면 버튼 통일.
- 하단 내비게이션: 기존 아이콘 경로·크기·동작은 유지, 배경/활성색만 공통 테마 사용.
- KEEP GOING: 기존 이미지 확대, 목표 카드 오른쪽 배치, 아래 경계에서 의도적으로 잘림.
