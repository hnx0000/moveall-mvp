# 운동 지식과 실시간 피드백 안전 정책

MoveAll은 운동 참여를 돕지만 의료기관이나 자격 전문가를 대체하지 않습니다. 운동 지식과
실시간 피드백 기능은 잘못된 조언이 신체 피해로 이어질 수 있다는 전제에서 개발합니다.

## 출시 전 필수 조건

1. 전문가 신원, 자격, 활동 범위와 이해충돌을 검증합니다.
2. 모든 지식 문서에 출처, 대상, 금기사항, 작성자, 검수자, 버전과 검수 날짜를 기록합니다.
3. 전문가가 승인하지 않은 문서는 DRAFT로 유지하고 사용자 맞춤 권고에 사용하지 않습니다.
4. 검수된 문서도 유효기간과 재검수 조건을 갖습니다.
5. 사용자가 부작용, 위험 조언, 오래된 내용을 신고할 수 있어야 합니다.
6. 수정과 철회 내역을 감사 가능하게 보존합니다.

## 개인화 경계

- 나이, 질환, 임신, 부상, 약물, 환경 위험을 모르는 상태에서 운동 처방을 생성하지 않습니다.
- 통증을 참고 계속하라거나 자격자의 진료를 미루게 하는 표현을 금지합니다.
- 다이빙, 수영, 고산 등산, 극한 기온 운동은 일반 운동보다 높은 안전 수준을 적용합니다.
- 실시간 피드백은 센서 오차, 데이터 지연, 연결 끊김을 항상 고려합니다.
- 센서 데이터가 없거나 신뢰도가 낮으면 추정값을 사실처럼 표시하지 않습니다.

## 긴급 신호

흉통, 실신, 심한 호흡 곤란, 갑작스러운 마비·혼란, 심각한 출혈, 수중 사고 등 즉각적인
위험 신호에는 운동 최적화 조언보다 운동 중단과 지역 응급 절차 안내를 우선합니다.

## 웨어러블과 개인정보

- 필요한 권한만 요청하고 거절해도 핵심 앱을 사용할 수 있게 합니다.
- 원시 건강 데이터의 수집 목적, 보관 기간, 공유 대상을 명확히 알립니다.
- 광고 타기팅과 건강 데이터를 기본적으로 분리합니다.
- 전송과 저장 시 암호화하고 사용자 삭제·내보내기 절차를 제공합니다.
- 각 플랫폼의 HealthKit, Health Connect 및 워치 제조사 정책을 출시 시점에 재검토합니다.

## 이번 기반의 적용 상태

- 모든 종목 지식은 DRAFT로 표시됩니다.
- EXPERT_REVIEWED에는 검수자와 검수 시각이 필수라는 DB 제약조건이 있습니다.
- 앱 화면과 API 모두 의료 대체 불가 및 중단 신호를 노출합니다.
- 실제 맞춤 운동 처방과 실시간 안전 판단은 구현하지 않았습니다.
