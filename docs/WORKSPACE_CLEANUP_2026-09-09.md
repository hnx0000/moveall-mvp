# 현재 버전 확정 및 폴더 정리 — 2026-09-09

## 기준 앱

사용자가 로컬 앱을 확인한 뒤 최신 버전으로 교체하고 이전 백업을 제거하도록 승인했습니다. 안정화 수정본은 이미 메인 프로젝트에 통합되어 있어, `apps/mobile`, `apps/api`, `packages/contracts`를 현재 작업 원본으로 유지했습니다.

- 정리 전 안정화 대상 105개 파일 재비교: 103개 일치, 프로필 보상 메뉴 제거와 독립 지도 진입 경로를 보존한 수동 병합 2개 확인.
- 정리 후 통합 소스 105개 모두 직전 내용과 일치(개행을 정규화한 SHA-256 비교). 별도 정리 대상인 `scripts/characters.mjs`는 가상인물 생성 경로를 현재 보관함 위치로 수정.
- `main`의 다른 미커밋 변경, 기존 파일 삭제 상태, 독립 지도 MVP, Git index를 보존.
- 현재 미리보기: `http://localhost:8081/profile`. **데모 모드**이며 이번 정리는 실제 운영 인증·DB 반영이나 공개 배포를 뜻하지 않음.

### 의존성과 Git 보호

- 현재 앱의 의존성 링크 2,481개를 검사했고, 이전 백업을 가리키는 링크는 없었습니다.
- 백업 작업본에서 현재 앱을 가리키던 Junction 63개는 **링크 자체만 먼저 해제**했습니다. 원래 `node_modules`는 삭제하지 않았습니다.
- 휴지통으로 보낸 격리 작업본의 오래된 Git 연결 정보 1개만 정리했습니다.
- `codex/stabilization-20260908` 브랜치와 안정화 커밋 `4e4f1552394b37ffab8125bbc7fe9a95702c526a`는 보존했습니다.
- 휴지통에서 백업을 복원해 별도 실행하려면 의존성과 Git 작업 폴더 연결을 다시 준비해야 합니다. 메인 프로젝트를 이전 파일로 덮어쓰지 마세요.

## 정돈한 위치

| 이전 위치                         | 현재 위치                                           |
| --------------------------------- | --------------------------------------------------- |
| `moveall-design-export`           | `개발자료 보관함/초기 디자인/moveall-design-export` |
| `tmp/pdfs`의 제작·검증 Python 3개 | `개발자료 보관함/앱개발 기초/문서 제작 스크립트`    |

이동한 원본 22개 파일의 SHA-256 일치를 확인했습니다. 디자인 이식본의 ESLint·Prettier 제외 경로와 안내 문서도 함께 수정했습니다. 가상인물 생성 스크립트는 이미 정리된 `개발자료 보관함/가상인물 리스트`를 사용하도록 수정했고, 생성 명령을 실행해 기존 인물 자료를 덮어쓰지는 않았습니다.

지도·인물 사진·로고·PSD·PDF 원본은 삭제하지 않았습니다. `artifacts/map-boundary-upgrade`에는 지도 경계 원본·라이선스·도구가 포함되어 있어 보존했고, `prototypes`, 대시보드, 현재 빌드·의존성 경로도 유지했습니다.
