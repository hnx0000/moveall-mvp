# GROOV 종목별 네온 메달 60개 시안

6종목 × 10개. 종목의 장비·동작·공간이 메달 형태 자체로 연상되도록 구성한 독립 디자인 대안입니다. 관리자 디자인 보관함에 추가했으며, 등급 시리즈·최종 지급 조건이나 실제 MY 획득 메달에는 적용하지 않았습니다.

## 앱 보관함 · 2026-09-15

- 관리자 MY → 설정 → 디자인 보관함 → 네온 메달 60
- 경로: `/reward-collection?tab=neon` (관리자 접근 제한 유지)
- 6종목 필터, 각 10종 목록, 개별 확대 및 이전·다음 보기
- 기존 입체 메달 106종과 스탬프 탭 보존
- 앱 표시용 WebP 60개는 원본 해상도를 유지하며 약 22.3 MB입니다. PNG 원본은 이 폴더에 보존합니다.
- 기록 수치는 디자인 예시이며 실제 지급 조건이 아닙니다. 공유앱 배포는 이번 GitHub 저장과 별개입니다.

기본 제공 이미지 생성 도구(imagegen)로 각 이미지를 개별 제작합니다. 실제 생성된 결과는 아래 원본 링크로 확인할 수 있습니다. 기록은 디자인 비교용 가상 예시입니다.
