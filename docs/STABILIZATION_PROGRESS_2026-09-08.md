### 실제 PostgreSQL 16.15 — 운영과 분리된 로컬 DB

마이그레이션 전체 적용 후 임시 테스트 DB에서 다음 9개를 통과했습니다. 테스트 DB는 각 실행 후 정리했습니다.

1. 서버 전용 테이블 6개의 RLS/FORCE RLS와 PUBLIC/anon/authenticated 권한 검사.
2. 같은 키 운동 10건 동시 요청 → 운동/원장/리그 가산 각각 1개. 입력 변경 409, 삭제 후 재생성 410.
3. 게시물 8건 동시 요청, 원장 rollback, 숨김/삭제 후 재요청 처리.
4. refresh 동시 요청 8개 중 1개만 회전, 폐기된 세션 재사용 차단.
5. 비공개 게시물 120개 앞에 있어도 공개 피드를 누락하지 않음. 팔로우/차단/스토리 만료 반영.
6. 가입·로그인·게시·댓글·팔로우·좋아요·운동을 새 DB 연결에서 재조회해 영속성 확인.
7. 크루 삭제 후 기존 성공 게시물 재요청은 복원, 새 잘못된 크루 요청은 미생성 오류.
8. 푸시 A→B 계정 이전 후 오래된 A 해제가 B 등록을 지우지 않음, B 세션 폐기 반영.
9. 공유 카드 게시물의 공개범위가 바뀌면 대화에서도 숨김 처리.

로컬 테스트 DB의 backend 소유자와 운영 Supabase의 실제 연결 역할·기존 데이터가 같다는 의미는 아닙니다. 일반 API 테스트 실행에서는 이 9개가 환경변수 미설정으로 skip되며, 별도 실제 DB 실행에서 9/9 통과했습니다.
