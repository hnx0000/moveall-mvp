# 피드 댓글·삭제 / 활동 지도 변경

## 로컬 구현

- 댓글 및 한 단계 답글, 댓글·답글별 좋아요/취소와 개수. 답글은 원본 댓글 아래 표시.
- 좋아요 PUT/DELETE는 멱등 처리. API는 인증, 게시물·댓글 일치, 차단, 보관, moderation 상태를 검사.
- 내 게시물 삭제는 기존 소유자 전용 DELETE API를 사용하고 중앙 확인 창을 먼저 표시. 게시물·댓글·답글·좋아요·공유 연결만 제거하며 원본 운동 기록은 보존.
- 미리보기의 게시물/댓글/좋아요 상태 저장. 실제 계정은 PostgreSQL을 사용하며 미리보기 저장과 구별.
- 피드 당겨서 새로고침 중 이전 응답이 댓글 변경이나 삭제 결과를 되돌리지 않도록 처리.
- 오늘의 활동은 GPS 안내 → 지도 → 메인 수치·기록 시작 → 상세 수치 순서. 지도 채도/대비와 중복 안내를 줄이고 현재 위치 표시는 유지. 기존 OSM 출처 표시는 보존.

## 다음 공개 최신화 때 필요한 일

- 새 PostgreSQL 마이그레이션 `0014_comment_replies_likes.sql`을 API 공개 전 적용한다. 댓글의 부모 연결과 `comment_likes` 테이블이 없으면 새 API의 피드 조회가 실패하므로 API만 먼저 교체하면 안 된다.
- 마이그레이션은 기존 댓글을 보존하며 기본적으로 원댓글로 취급한다. 새 테이블은 기존 서버 전용 RLS 정책을 따른다.
- 이 작업에서는 운영 DB 변경, GitHub push, 공개 배포, 실제 기기/브라우저 조작 테스트를 수행하지 않았다.
