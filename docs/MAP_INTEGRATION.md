# GROOV 지도 이식 (2026-09-09)

## 연결

- `+ → 오늘의 활동`: `GroovCourseMap`으로 교체. 카드 탭으로 코스지도 전체화면, 뒤로가기로 기존 기록 화면 복귀.
- 운동 중 지도: 같은 코스지도를 사용. 앱의 `LiveWorkoutRecorder`만 GPS 기록·거리·시간·저장을 소유하며, 지도에는 좌표 사본만 전달한다. 코스 설계선과 실제 기록선은 별도 소스다.
- `지역 리그`: 구형 SVG 지도를 제거하고 `GroovRankingMap`으로 교체. 기존 `api.league` 조회·필터·지역 상세 집계는 유지한다.
- 지도 원본은 `prototypes/groov-korea-25d-map`, 앱 연결부는 `apps/mobile/src/components/groov-*map*`, 로컬 코스 보관은 `src/features/maps`로 분리했다.

## 실행 / 패키징

앱의 dev / web / native dev / build 명령이 `scripts/sync-map-runtime.mjs`를 먼저 실행한다. 지도 HTML·모듈·지리 자료를 `apps/mobile/public/groov-maps`에 복사하며, 로컬 서버 코드·코스 데이터베이스·테스트 파일은 제외한다. 이 생성 폴더는 Git에서 제외된다. 8095 서버에 의존하지 않는다.

웹은 같은 앱 주소의 `/groov-maps/`를 사용한다. 네이티브 개발은 Metro 주소를 사용하고, 네이티브 배포 빌드는 `EXPO_PUBLIC_MAP_ORIGIN`에 지도 파일이 포함된 HTTPS 앱 배포 주소를 설정해야 한다. WebView 네이티브 의존성을 추가했으므로 기존 개발 빌드는 재빌드해야 한다. 이번 작업에서는 공개 사이트를 배포하지 않았다.

## 데이터 / 제한

- 앱에 이식된 랭킹은 서버 스냅샷만 사용한다. 데모 점수 생성·주기적 가산은 차단하며, 미집계 지역은 0점·순위 없음으로 표시한다.
- 부모 창·같은 origin·지도별 channel을 확인한다. 인증 토큰은 URL·메시지에 전달하지 않는다.
- 코스 저장·선택은 현재 **계정별 기기 로컬 저장**이다. 서버 동기화 API는 아직 없으며 여러 기기 간 동기화되지 않는다. 최대 100개.
- 경로·주소·자동 코스는 교체 가능한 BRouter / Photon / Overpass 어댑터를 사용한다. 외부 데이터가 없거나 요청이 실패하면 오류를 표시하며 임의의 경로를 그리지 않는다. 정확한 상세 주소가 제공자 자료에 없으면 주변 후보와 구분한다.
- 피드·편집기 등 다른 용도의 `WorkoutMap`은 유지했다. 요청받은 기록 화면과 지역리그 슬롯의 기존 지도 렌더러만 교체/제거했다.

## 검증

- 지도 기능 회귀 테스트 87개.
- 앱 연결·부모 메시지 검증·코스 저장/복원/계정 분리·실제 점수/경로 분리·리그·GPS 병합·기록 복구/수명주기 테스트 27개.
- 모바일 TypeScript 검사, 변경한 지도 모듈 lint, Expo 웹 export.
- 앱 주소의 지도 진입 파일·모듈·전국 자료 HTTP 200 및 올바른 MIME 확인.
- 공개 장소 좌표로 실제 경로 응답, 상세 주소 검색 응답, 경로/검색 제공자의 브라우저 CORS 허용 확인.

브라우저 화면 수동 클릭 검증 및 휴대폰 실기기 GPS 주행 검증은 별도다. 네이티브 배포 주소 설정 후 Android/iOS WebView·권한 검증도 필요하다.
